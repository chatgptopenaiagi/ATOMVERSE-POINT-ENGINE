# Perceptual projection

The renderer observes copied snapshots. Camera orbit, zoom, focus and view selection never modify the kernel. The primary 3D view uses the same one spherical entity and its geometric facets. A cached unit-sphere display list reduces repeated CPU-to-driver calls; radius and position remain draw transforms.

| View | What it shows | What it does not imply |
|---|---|---|
| Sphere | Current XYZ, radius, RGBA and idealized wall | Physical atom or real material interaction |
| Wave | Analytic oscillator curve over a four-second display interval | Measured waveform or stored samples |
| Spiral | A mathematical spiral whose orientation follows oscillator phase/time | A second independent entity or a recorded movement |
| Signal | Recent observed software oscillator values | Complete high-frequency archival history |
| Data | Versioned numerical state as JSON | Human perception or interpretation |

Projection is configurable output. The same state can be inspected without a visible 3D scene. The historical movement trail, explicit polyline trajectory and equation-defined curve remain distinct concepts. No independent multi-point structure is introduced in this mission.
