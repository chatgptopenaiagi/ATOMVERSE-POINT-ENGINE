# Two worlds, one atomic entity

**COMPUTATION BEFORE PERCEPTION.**

The human creator distinguishes two domains. World 1 is the physical and computational infrastructure: processors, memory, electrical power, clock frequencies, software execution, mathematical operations, inference and storage. World 2 is human perceptual experience: visible geometry, apparent motion, color, brightness, interpretation and belief.

The first artificial entity is one spherical point. Its sphere is a representation. Its mathematical state is authoritative within the software model. Its movement is a state transformation. Its memory is a sequence of recorded events. Qwen contributes explicitly identified interpretation. None of this establishes physical atomic matter, subjective consciousness, or a guarantee of human perception.

**ENERGY → COMPUTATION → STATE → TRANSFORMATION → SIGNAL → PERCEPTION → INTERPRETATION**

In version 0.2, the state can evolve without a graphical application through headless execution. When the operator enables “Keep mathematical engine running,” closing the visualization leaves the engine and recorder running behind a system-tray control. Ordinary exit still shuts down cleanly. This is process independence from visualization, not persistence after the engine process or operating system stops.

The original [one-point vision](ORIGINAL-HUMAN-VISION.md) remains foundational. Expanding the population is deferred until this entity is verified. The two-world principle guides extension of the existing engine; it does not replace the working XYZ kernel with a generic scene engine.
