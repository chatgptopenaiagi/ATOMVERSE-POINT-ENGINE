# Foundation before population

1. Preserve one precise, controllable entity and exact command/history semantics.
2. Provision the dedicated SQL database with an authorized account and benchmark permanent storage separately.
3. Extend retention/archive tooling, crash-durable command acknowledgement and longer stability tests.
4. Expand the reviewed Qwen command/evidence suite and measure latency for representative workloads.
5. Add a second independently identified entity and a true connecting line; keep trails, curves and connected entities distinct.
6. Benchmark array-based transformations and interactions before increasing population.
7. Introduce collective behavior, complex structures and artificial worlds only after their underlying state and history are verified.

A persistent service with multiple observers, arbitrary physical-material models, subjective consciousness and million-entity performance are not implemented claims.
